# Chris-bot (디스코드 서버 편의 기능 봇)

디스코드 서버 운영 및 이용 편의를 위해 제작된 Python(`discord.py`) 기반 봇입니다.
다른 AI 세션(Claude, Antigravity 등)에서 이어서 작업할 때는 이 문서와 [`CLAUDE.md`](./CLAUDE.md)를 먼저 읽고 규칙을 따라 주세요.

---

## 주요 기능

### 1. 내 포스트 직접 삭제 (`/포스트삭제`)
디스코드 포럼(또는 스레드)에서 자신이 만든 포스트에 다른 사람이 댓글을 달면, 관리자 권한(`Manage Threads`)이 없는 일반 유저는 자신의 포스트를 통째로 지울 수 없는 문제를 해결합니다.

- **작동 방식**:
  1. 관리자가 허용한 채널(포럼 또는 텍스트 채널) 안의 포스트(스레드)에서 작성자가 `/포스트삭제`를 입력합니다.
  2. 봇이 **1) 허용된 채널인지**, **2) 명령어 실행자가 해당 포스트 작성자(`owner_id`) 본인인지** 확인합니다.
  3. 맞다면 작성자 본인에게만 보이는 메시지(`ephemeral`)로 **`[🗑️ 삭제 확인]`** / **`[취소]`** 버튼을 띄웁니다.
  4. **`[🗑️ 삭제 확인]`**을 누르면 포스트 전체를 즉시 삭제합니다.

- **관리자 설정 명령어** (`채널 관리` 권한 필요):
  - `/포스트삭제채널 추가 [채널]`: 포스트 작성자 직접 삭제를 허용할 채널 등록
  - `/포스트삭제채널 제거 [채널]`: 허용 채널 목록에서 제외
  - `/포스트삭제채널 목록`: 현재 등록된 허용 채널 목록 확인

- **필수 봇 권한**:
  - `Send Messages`, `Send Messages in Threads`
  - **`Manage Threads` (스레드 관리)** — 포스트(스레드)를 삭제하기 위해 반드시 필요합니다.
  - Privileged Gateway Intents(Message Content 등)는 필요하지 않습니다.

## 폴더 구조

```text
Chris-bot/
├── bot.py             # 메인 봇 코드
├── requirements.txt   # 파이썬 패키지 목록 (discord.py, python-dotenv)
├── .env.example       # 환경변수 예시 파일 (실제 토큰은 .env 에만 보관)
├── .gitignore         # .env, .venv, data/ 등 Git 업로드 제외 설정
├── CLAUDE.md          # AI 에이전트 작업 지침 및 bot2 서버 배포 안내
└── data/
    └── config.json    # 서버별 허용 채널 설정 (자동 생성, Git 제외)
```

## 서버 배포 (`bot2` 서버 기준)

- **설치 경로**: `/opt/bots/Chris-bot`
- **서비스 이름**: `bot-chris.service`
- **런타임**: Python 3.12 (`.venv` 가상환경)
