# Chris-bot (디스코드 서버 편의 기능 봇)

디스코드 서버 운영 및 이용 편의를 위해 제작된 Python(`discord.py`) 기반 봇입니다.
다른 AI 세션(Claude, Antigravity 등)에서 이어서 작업할 때는 이 문서와 [`AGENTS.md`](./AGENTS.md)를 먼저 읽고 규칙을 따라 주세요.

---

## 주요 기능

### 1. 내 포스트 직접 삭제 (`/포스트삭제`)
디스코드 포럼(또는 스레드)에서 자신이 만든 포스트에 다른 사람이 댓글을 달면, 관리자 권한(`Manage Threads`)이 없는 일반 유저는 자신의 포스트를 통째로 지울 수 없는 문제를 해결합니다.

- **일반 유저 명령어**:
  - `/포스트삭제`: 허용된 채널 안의 포스트(스레드)에서 작성자(`owner_id`) 본인이 실행하면 `[🗑️ 삭제 확인]` 버튼이 뜨고, 확인 시 포스트 전체를 즉시 삭제합니다.
- **관리자 설정 명령어** (`채널 관리` 권한 필요):
  - `/포스트삭제채널 추가 [채널]`: 포스트 작성자 직접 삭제를 허용할 채널 등록
  - `/포스트삭제채널 제거 [채널]`: 허용 채널 목록에서 제외
  - `/포스트삭제채널 목록`: 현재 등록된 허용 채널 목록 확인

---

### 2. 등급 취합 시스템 (`/등급평가`, `/등급관리`)
특정 채널에서 등급 조정 시즌을 활성화하면 심사위원들이 대상 유저에 대한 등급 평가를 제출하고, 관리자가 산술평균(반올림)으로 취합 · 예외 수정 · 최종 승인(역할 자동 변경 및 공지 문구 출력)할 수 있는 시스템입니다.

#### ➕➖ 세부 등급(점근적 점수) 자동 계산
기본 등급만 등록해 두면(예: `C = 2`, `B = 3`), 투표 시 `+` 또는 `-`를 붙여 점근적으로 올라가거나 내려가는 세부 점수를 줄 수 있습니다:
- **`+`가 $k$개일 때**: $\text{기본점수} + 0.5 \times (1 - 2^{-k})$
  - 예(`C = 2`): `C+` = `2.25`, `C++` = `2.375`, `C+++` = `2.4375` ... (`2.5`에 점근)
- **`-`가 $k$개일 때**: $\text{기본점수} - 0.5 \times (1 - 2^{-k})$
  - 예(`B = 3`): `B-` = `2.75`, `B--` = `2.625`, `B---` = `2.5625` ... (`2.5`에 점근)

#### 🎖️ 역할별 투표 가능 등급 상한선 세분화
심사위원 역할마다 투표할 수 있는 최대 등급을 다르게 지정할 수 있습니다.
- 예: `@일반심사위원`은 최대 `B`까지만 투표 가능, `@수석심사위원`은 최대 `A`(또는 전체 등급)까지 투표 가능

#### 명령어 목록
- **심사위원 및 일반 유저 명령어**:
  - `/등급평가 [대상] [등급]`: 시즌이 활성화된 지정 채널에서 심사위원이 대상 유저의 등급(예: `C`, `C+`, `C++`, `B-`, `B--` 등)을 제출합니다. 부여한 등급/점수는 평가자 본인에게만 비밀 메시지(`ephemeral`)로 보이고, 채널에는 결과 없이 **"누가 누구에 대한 등급 평가를 완료(또는 수정)했습니다"**라는 완료 안내 메시지만 모두에게 공개됩니다.
  - `/등급박탈`: 일반 사용자가 현재 본인이 보유하고 있는 **등급 역할**을 스스로 박탈(반납)합니다. 실수 방지용 확인 버튼을 거치며, **등급을 박탈하더라도 이미 부여받은 심사위원 역할은 해제되지 않고 그대로 유지**됩니다.

- **관리자용 명령어** (`서버 관리` 권한 필요):
  - `/등급관리 등급등록 [등급기호] [점수] [역할] [동시부여심사역할(선택)]`: 기본 등급 기호(예: `N`, `D`, `C`, `B`, `A`), 숫자 점수, 실제 디스코드 역할(및 해당 등급을 받게 될 때 동시에 자동으로 부여할 심사위원 역할)을 등록합니다.
  - `/등급관리 등급심사연결 [등급기호] [심사역할(선택)]`: 이미 등록된 특정 등급을 달성했을 때 동시에 부여할 심사위원 역할을 설정(또는 비워두면 해제)합니다.
  - `/등급관리 등급삭제 [등급기호]`: 등록된 기본 등급을 삭제합니다.
  - `/등급관리 아카이브채널 [채널(선택)]`: 이의제기나 부정 의혹 확인을 위해 **누가 누구에게 어떤 등급(점수)을 투표했는지 실시간 기록 및 시즌 최종 취합 영수증을 영구 보관할 아카이브 채널**을 지정합니다.
  - `/등급관리 심사역할지정 [역할] [최대등급(선택)] [플러스허용(선택)]`: 심사위원 역할을 지정하고 해당 역할이 투표할 수 있는 최대 등급 상한선(예: `B`까지만 투표 가능, 비워두면 모든 등급 가능)을 설정합니다.
  - `/등급관리 심사역할해제 [역할]`: 심사위원 역할을 해제합니다.
  - `/등급관리 설정목록`: 현재 등록된 등급, 아카이브 채널, 심사위원 역할별 투표 상한선, 시즌 상태를 확인합니다.
  - `/등급관리 시즌시작 [채널] [기록초기화]`: 지정한 채널에서 등급 조정 시즌을 시작합니다.
  - `/등급관리 시즌종료`: 등급 평가 제출을 마감합니다.
  - `/등급관리 취합현황 [대상(선택)]`: 현재까지 모인 평가들의 산술평균 점수, 반올림 취합 등급, 공지 문구 미리보기(또는 특정 대상의 심사위원별 상세 내역)를 확인합니다.
  - `/등급관리 평가삭제 [대상] [심사위원(선택)]`: 특정 심사위원이 남긴 평가 1건을 삭제하거나, 대상 유저의 전체 평가를 삭제합니다.
  - `/등급관리 등급수정 [대상] [변경할등급]`: 변수 상황 시 산술평균과 무관하게 특정 유저의 최종 등급을 수동 지정(또는 `RESET`으로 초기화)합니다.
  - `/등급관리 최종승인`: 취합된 등급을 최종 확정하여 **대상 유저들의 디스코드 등급 역할을 자동으로 변경**하고 공지용 문구를 출력합니다. 승인 즉시 아카이브 채널에 전체 상세 투표 내역을 영구 기록하며, 다음 시즌에 이전 평가가 섞이지 않도록 현재 시즌 평가 데이터를 자동 초기화합니다.

## 필수 봇 권한

- `View Channels`, `Send Messages`, `Send Messages in Threads`
- **`Manage Threads` (스레드 관리)** — 포스트 삭제(`/포스트삭제`)에 필수
- **`Manage Roles` (역할 관리)** — 등급 최종 승인 시 유저 역할 자동 변경에 필수 *(서버 설정 → 역할 목록에서 `Chris Bot` 역할이 등급 역할들보다 위쪽에 위치해야 합니다)*

## 서버 배포 (`bot2` 서버 기준)

- **설치 경로**: `/opt/bots/Chris-bot`
- **서비스 이름**: `bot-chris.service`
- **런타임**: Python 3.12 (`.venv` 가상환경)
- 자세한 서버 접속 및 배포 절차는 [`AGENTS.md`](./AGENTS.md)를 참고하세요.
